The aim of [this project](https://github.com/erazemk/sic) is to be the most complete learning resource about SIC and SIC/XE available on the internet.

You're currently viewing the website portion of the project, with documentation about SIC and SIC/XE, but feel free to also check out the [GitHub repo](https://github.com/erazemk/sic)) containing a compiler from [Go](https://go.dev) to SIC assembly, a SIC assembler, linker, and simulator, and example code showing the outputs of the compilation stages.
