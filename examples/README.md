# Examples

This directory contains examples of tuples of Go code, the equivalent SIC assembly code (not necessarily what the compiler produces, but functionally equivalent), and the corresponding SIC object code.

All the Go and SIC assembly examples are well-commented, to make it easy for everyone to understand what the code is doing, even if not familiar with SIC assembly syntax.

For an explanation of how SIC assembly code is turned into object code, see the documentation chapter on [object code](https://sic.erazemk.com/chapters/object-code).
